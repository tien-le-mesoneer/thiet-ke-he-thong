- 2026-08-24 (CORRECTION): my earlier '33% interpolation error' claim was invalid - it compared k6 and histogram_quantile over DIFFERENT time windows. On matched data (364,240 reqs, k6 p99=22.47ms) histogram_quantile gives 22.82ms = 1.6% error. The real argument for counting is bucket WIDTH: with the 0.05 boundary the SLI is exact (99.8268%, 17.3% of budget); remove it and the enclosing 0.025-0.1 bucket makes interpolation report 99.5633% = 43.7% of budget - 2.5x the burn from the same data. Always compare metrics over the same window before drawing a conclusion.
